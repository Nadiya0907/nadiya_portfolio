# Nadz Portfolio — Python Automation & AI/ML Developer

Spring Boot + MySQL backend, static HTML frontend.

## Backend
- Java 17 + Spring Boot 3.3
- MySQL (Railway-hosted)
- REST endpoints: /api/health, /api/contact, /api/projects, /api/github/repos

## Frontend
- `frontend/index.html`
- Calls backend via `API_BASE`

## Deployment
- Backend → Railway (root: `backend`)
- Frontend → Netlify (base: `frontend`)
